Advanced Elementor Addon Widgets & Extensions Toolkit.

== Description ==

KatlaKit is a premium Elementor addon library that adds advanced widgets, extensions, templates, and WooCommerce elements directly inside the Elementor editor. 
It is fully modular, lightweight, scalable, and production-ready.

Features include:
* 30+ Advanced Widgets (Basic, Creative, Marketing, WooCommerce)
* Modular architecture (only load what you use)
* Modern glassmorphism UI support
* Powerful Elementor extensions (Sticky, Parallax, Custom Breakpoints)

== Installation ==

1. Upload the `katlakit` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to the KatlaKit menu in the dashboard to enable/disable specific widgets.
4. Edit any page with Elementor and look for the KatlaKit categories.

== Frequently Asked Questions ==

= Does it require Elementor Pro? =
No, KatlaKit works perfectly with the free version of Elementor.

= Does it slow down my website? =
No, KatlaKit is built with performance in mind. It only loads assets for the widgets you actually use on a page.
